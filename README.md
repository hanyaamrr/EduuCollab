# EduCollab

EduCollab is a study group platform where students can create, join, and collaborate in study groups.

## Technologies

* ASP.NET Core
* React
* SQL Server
* Entity Framework Core
* SignalR

## Features

* Authentication with Admin, Group Creator, and Student roles
* Admin approval of accounts and study groups
* Study group creation and management
* Search by subject, location, and meeting time
* Join requests and member management
* Study material upload and download
* Material tagging
* Group discussions and comments
* Real-time communication using SignalR
* Meeting notifications

## Project Structure

```text
EduuCollab/
├── backend/

```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/hanyaamrr/EduuCollab.git
```

Switch to the `dev` branch:

```bash
git checkout dev
```

Configure the database, then run the ASP.NET Core backend and React frontend.
